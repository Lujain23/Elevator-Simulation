
# Elevator Simulation

An interactive C++ elevator simulation featuring multiple floors and elevators, breakdown handling, help requests, and real-time console updates.

## Features
- Multiple elevators operating across multiple floors
- Elevator movement and floor requests
- Breakdown handling and help requests
- Real-time console updates

# Running Project
1. Clone the repository.
2. Open COMP3004_A3.pro in Qt Creator.
3. Configure the project using an available Qt kit.
4. Build and run the application.
